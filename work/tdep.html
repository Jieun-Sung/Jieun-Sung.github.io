TDEP

Target-perturbed Differential Expression Profile. Most drug–target interaction models return a binary yes or no. TDEP returns the transcriptome-wide response expected from inhibiting the target, so the interaction call arrives together with a gene-level account of what engaging that target would do.

Jieun Sung, Sookyung Kim, Wankyu Kim · under review

  • AUROC 0.873 unseen drug
  • 10,086 genes per profile
  • 938,089 curated interactions
  • Poster
  • Code
  • Archive (Zenodo)

Problem

Drug–target interaction prediction splits into two families, and each gives up something the other has.

  • Structure-based methods (MolTrans, GraphDTA, DrugBAN) read ligand and protein structure. They are accurate and work on any molecule, but say nothing about what happens biologically once the target is engaged.
  • Omics-based methods (ssGCN, FRoGS) compare drug-induced transcriptomes against shRNA knockdown profiles. That is biologically grounded but rests on a shaky representation: shRNAs sharing a miRNA-like seed sequence produce more similar signatures than shRNAs targeting the same gene, so off-target noise can dominate the very profile used to define the target.

Both return only a binary label. Neither tells you which genes move, which is what a mechanistic hypothesis actually needs.

Approach

TDEP takes an intermediate position: the target is represented by its amino acid sequence, the ligand by its Connectivity Map profile. The model never uses shRNA profiles as a target representation, which removes the off-target noise at its source.

Two modules run in sequence:

  • PLM. A frozen protein language model embeds the target sequence. Three were compared: Gene2Vec (200-d), ProtBERT (1,024) and ESM2 (1,280).
  • PPG1. Fully connected layers map that embedding to a gene-wise score vector over G = 10,086 genes.
  • PPG2. Each score becomes a node feature and is refined by a multi-head graph attention network over the STRING co-expression network, so connected genes exchange information while isolated genes update only through self-connections. A final linear layer emits the predicted profile.

Training signal comes only from the binary interaction label. For each drug–target pair the model scores its predicted profile against the observed drug-induced profile using a weighted dot product, which emphasises strongly perturbed genes, plus a Pearson correlation term for directional concordance (α = 0.8). That score is the logit, optimised with binary cross-entropy. The gene-level output is therefore a target-specific discriminant over drug profiles — that it also carries biological structure is something the paper tests rather than assumes.

Results

Benchmark, unseen-drug split. Mean ± SD across six cell lines and ten negative-sampling seeds (n = 60), balanced 1:1 sampling following the ssGCN and FRoGS protocol.

Method AUROC AUPRC F1
TDEPESM2 0.873 0.872 0.810
TDEPProtBERT 0.865 0.865 0.805
DrugBAN (structure) 0.848 0.856 0.786
GraphDTAGATNet (structure) 0.828 0.860 0.763
MolTrans (structure) 0.820 0.849 0.749
ssGCN (omics) 0.593 0.602 0.571
FRoGS (omics) 0.524 0.520 0.518

TDEP closes the gap to the best structure-based models from the omics side — the margin over DrugBAN rests on four of six cell lines and is not significant — while clearly exceeding the omics-based baselines. A memorisation control confirms the accuracy is not lookup: describing each target by the average profile of drugs already known to bind it reaches only 0.623.

Ablation. The two modules turn out to do different jobs, and which one matters depends on the generalisation regime.

Configuration Unseen drug Unseen target
Full model 0.923 0.663
No PLM 0.921 (p = 0.63) 0.610 (p = 0.0039)
No PPG2 0.697 (p = 0.0039) 0.664 (p = 0.92)

When targets are well represented in training, the graph module carries the signal and the sequence encoder is redundant. When the target is unseen, that reverses: sequence-derived priors become the only route to generalisation. Both are kept because deployment spans both regimes.

Transferability. Same-cell mean AUROC 0.899, cross-cell 0.888, multi-cell ensemble 0.910. The small cross-cell drop indicates much of what TDEP learns is shared across cell lines rather than cell-type-specific. The ensemble gain came from variance reduction, not from the similarity weighting — a uniform-weight ensemble performed identically, which the paper reports rather than claiming the weighting worked.

Does the gene-level output mean anything? Because drugs are polypharmacological, an observed profile mixes all engaged targets. But genes consistently perturbed across structurally unrelated drugs sharing one target are more likely to reflect that target. For KCNH2, seven active drugs gave 45 consensus DEGs, and cosine similarity between the TDEP profile and observed responses over those genes was 0.31 against 0.02 for random targets (KS p = 8.2×10−3). Extended to 234 targets, 9 of 11 drug-count strata were significant, with concordance rising as more drugs contribute.

Limitations

Stated in the paper, and worth repeating here rather than burying:

  • The unseen-drug split holds out drug identity alone, so test compounds may be close analogues of training ones. The reported numbers are an upper bound on generalisation to novel chemistry; a scaffold- or mechanism-based split would tighten them.
  • TDEP needs a Connectivity Map profile as input, which restricts it to ligands in that resource.
  • All training cell lines are established cancer lines.
  • It uses binary interaction labels and does not model binding affinity.
  • Biological validation leans on LINCS data sharing the Luminex platform used for training; concordance with other platforms was not consistently observed.
  • Disentanglement of individual target contributions is supported by the consensus-DEG analysis but not definitively demonstrated.
